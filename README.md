# HangarFlow

An organization-neutral aircraft maintenance work-order and quoting core based
on Planetrk's durable workflow ideas. Currency is calculated in integer cents
and labor retains minute precision.

```powershell
cargo test
cargo run
```

Next slices: customers/aircraft, discrepancies, parts traceability, logbook
entries, estimates/approvals, technician assignment, Form 337 support, and
invoice/accounting export.
